Converting a Password-Protected PDF to Word

If your PDF asks for a password before it opens, PDF2Wordly — like any converter — can't read it yet. Here's how to confirm that's the issue, remove the password yourself, and then convert normally.

Is your PDF actually encrypted?

Quick check

If the PDF asks for a password before it will even open in a viewer, or greys out printing and copying, it's encrypted. If it opens fine but the converter still fails, the cause is something else — see the troubleshooting guide instead.

Why the converter can't open it

PDF2Wordly rebuilds your document by reading its text, images, and layout. An encrypted PDF blocks that access at the file level — the same way it blocks printing or copying in a regular PDF reader — until the correct password is applied. There's no version of a converter, PDF2Wordly included, that can read an encrypted file without the password being removed first.

Removing the password

You only need to do this once, in a tool you already have. Use whichever matches your device:

On Mac

  1. Open the PDF in Preview and enter the password when prompted.
  2. Go to File → Export as PDF.
  3. Save the new copy — it opens without a password.

On Windows

  1. Open the PDF in Microsoft Edge or Adobe Acrobat with the password.
  2. Choose Print → save as "Microsoft Print to PDF".
  3. The printed copy is a new, unlocked PDF.

If you have Adobe Acrobat, its built-in "Remove Security" option under Tools → Protect does this in one step and keeps the original quality intact.

Converting once it's unlocked

Once the new copy opens without a password prompt, it converts exactly like any other PDF — upload it, click "Convert to Word," and download the .docx. Removing a password only changes the file's permissions, not its layout, so formatting comes through the same as it would for an unprotected file.

If you don't have the password

PDF2Wordly doesn't offer a way to bypass a PDF's encryption, and that's intentional — the protection is usually there for a reason. If the file isn't yours, or you've genuinely lost the password, the right next step is to contact whoever created or sent it to you.

Frequently asked questions

Why won't my password-protected PDF convert?

PDF2Wordly reads the text and layout of a PDF to rebuild it in Word. An encrypted file blocks that access until the password is removed, so the converter can't open it, even briefly.

Does PDF2Wordly store or see my password?

No. PDF2Wordly doesn't have a way to enter a password at all. You remove the password yourself, in your own PDF viewer, before uploading — the converter never sees it.

I don't know the password. What can I do?

If you don't own the document or don't have the password, PDF2Wordly can't help you bypass that protection, and neither should any tool — the encryption is there deliberately. Contact whoever issued the file.

Will removing the password change the PDF's formatting?

No. Removing a password only changes the file's permissions, not its content or layout. The formatting is preserved exactly, and the conversion to Word works the same way it would on any other PDF.
